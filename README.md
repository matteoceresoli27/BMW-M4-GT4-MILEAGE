# M4 GT4 Mileage – FS Motorsport

Web-app per controllare i chilometraggi dei componenti della BMW M4 GT4 EVO.
Limiti tratti dal Technical Customer Manual V2.3 (Appendice D – Running Times).

## Pubblicazione su Render
1. Carica questa cartella in un repository GitHub.
2. Su Render: **New → Blueprint** e scegli il repository (usa `render.yaml`),
   oppure **New → Static Site** con Build Command vuoto e Publish Directory `.`.
3. Render pubblica il sito su `https://<nome>.onrender.com`.

## Dati
I dati sono salvati nel browser di ogni dispositivo.
Per spostarli o conservarli: Impostazioni → Copia backup / Importa backup.
